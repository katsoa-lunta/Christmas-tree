# 🎄 我的圣诞树上，你在哪儿？

> 装饰你的树，再看看哪些朋友能登上树顶 —— 越懂我，挂得越高 ✨

一个**纯前端**的圣诞树互动小游戏：树主人回答 10 道关于自己的二选一小题，每答一题，树上就多挂一个装饰、点亮一层灯；答完生成一个专属链接。朋友打开链接、输入名字，猜这 10 题主人选了什么——每答对一题，写着名字的玻璃球就往上升一层。

> 🆕 本仓库版本额外带了两个原版页面没有的小功能：**🎨 换装** 和 **💾 本地备份**，见「本仓库新增」。

## 玩法

1. **树主人**：答 10 道关于自己的二选一题，生成专属分享链接。
2. **朋友**：打开链接，输入名字，猜这 10 题主人选了什么。
3. **落位**：9–10 分 → 树顶星星旁；7–8 分 → 树的 C 位；5–6 分 → 低枝；0–4 分 → 掉进礼物盒，最后被挂到一根小树枝上。
4. **回传**：朋友把「结果码」发给主人，主人粘贴导入，球就挂上自己的树，并进入排行榜。

> 💡 **没有服务器也能同步**：朋友答完会得到一串「结果码」，让 TA 发回给你，你在「我的树」里粘贴导入，球就挂上树并进入排行榜。

## 运行

单文件、零依赖、无需构建，也无需登录：直接用浏览器打开 `index.html` 即可；也可以把整个目录交给任意静态服务器托管。

## 本仓库新增（原版页面没有）

在保持原有玩法与「关于与声明」不变的前提下，仓库版只加了两处**纯本地**的小功能：

- **🎨 换装**：右上角「🎨 换装」在 🎄 经典红金 / ❄️ 冰雪蓝 / 🍬 糖果粉 三套配色之间循环。实现上只切换本机 CSS 变量，选择记在浏览器 `localStorage`（`xm_theme`），刷新后仍然保留。
- **💾 本地备份**：首页和「我的树」看板都有「导出备份 / 导入备份」。导出把本机所有 `xm_` 开头的记录打包成一个 JSON 文件下载到本机；导入从本地 JSON 文件恢复，可在换设备、换浏览器或清缓存前**手动**带走自己的树、题目与排行榜。导入只接受 `app: xmas-tree`、`v: 1` 且键名以 `xm_` 开头的记录，损坏或不匹配的文件会被拒绝。

这两项**都不新增网络请求、不上传任何数据、不依赖任何第三方图片 / 字体 / 脚本 / CDN**，也都不是 Cloudz.fun 提供的功能；新增代码同样为独立编写。因此下节「关于与声明」的每一条依旧成立。
